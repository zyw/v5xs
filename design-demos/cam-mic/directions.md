# v5xs 摄像头/麦克风占用检测弹窗 · 设计方案（三方向）

## 需求重述（顾问式）

v5xs 是深色、薄荷豆绿点缀的 macOS 菜单栏监控面板。要新增一块「隐私/占用检测」：摄像头与麦克风当前是否被占用、被谁占用，弹出面板呈现。这正是 OverSight 这类成熟产品做的事——帮用户发现「谁在偷看/偷听」。

## 情感基调

安心、可控、一眼看懂。不是警报器（红色警告全屏），而是「我在把关」的冷静仪表——因为你同时用 v5xs 看 CPU/温度，这块要融进同一套深色 UI。

## 硬约束（对齐现有 v5xs 设计语言）

「从已有代码读出来的真实值，非臆造」：
- 底色 `Palette.background` = rgb(0.12,0.16,0.15) #1F2927（近黑的深绿）
- 卡片 `Palette.card` = rgb(0.17,0.22,0.19) #2B3833
- 薄荷 `Palette.mint` = rgb(0.57,0.86,0.72) #92DBB8
- 蓝 `Palette.blue` = rgb(0.52,0.75,0.92) #85BFEB
- 琥珀 `Palette.amber` = rgb(0.96,0.78,0.52) #F5C785
- 弱化文字 `Palette.muted` = rgb(0.64,0.71,0.67) #A3B5AB
- 圆角 13px(卡片)/12px(面板)/5px(小徽标)；底部小字 10px、正文 11px、大数字 22-25px 圆体
- 系统状态语义：macOS 用「绿点=相机在用、橙点=麦克风在用」——**设计沿用这个颜色语义**，让用户天然读懂

## 诚实边界（产品事实，见 product-facts.md）

- 相机：绿点 + 可识别进程名；识别不到时写「有其他进程正在访问」，不编造名字
- 麦克风：橙点 + 进程名（macOS 14.2+ CoreAudio 进程对象给出）；低于则显示「摄像头在用」级布尔
- 「空闲」用空心点；「在用」用实心点 + 呼吸动画（与 v5xs 动画动物气质一致）

## 六个候选 → 挑三个

### 候选 A（最佳设计师｜克制派）— 叠加式
来源：Dieter Rams / 极简系统仪表。借：两级信息（先状态、后细节）、克制用色、充足留白。
主角：两颗指示灯 + 极少量文字。骨架：左灯右字。胆量：只用一个强调色（薄荷）统一两种占用。
form：监控仪表就该「一眼看到开关」。

### 候选 B（最佳设计师｜大气派）— 双卡对开
来源：瑞士网格 / 系统设置页。借：左右对称双栏、状态+进程并列、清晰分组。
主角：左「摄像头」右「麦克风」两块对开卡。骨架：对称双列。胆量：两块卡都用「状态→进程→最近」三级。
form：摄像头/麦克风是两件事，对开最清楚。

### 候选 C（秒数轮盘 35 → web 区）
取 35 % 20 = 15 → 实用主义彩虹文档（但这是深色场景，改为贴近 v5xs 的「暗色系统仪表」诠释）。
用 v5xs 的卡片语言做底部工具栏的检测条。
注：轮盘抽到的 15 号其实是浅色 docs，与深色场景不符，改为从题材长出的「深色系统侦测」诠释。

### 候选 D（现实参照｜OverSight）
OverSight 走的是「系统级弹窗」：一个大圆点 + 提示哪类设备被访问。借：突出「设备被访问」这一瞬间。
主角：一个大大的设备图标 + 状态。骨架：居中单卡。胆量：一次只强调一种占用。
form：被盗用是「瞬间事件」，就该像通知一样短促。

### 候选 E（东亚·佐藤可士和 极简符号）
半色块 + 大字标。深色下用「色块分割」表达两种设备。

### 候选 F（东亚·上海摩登装饰艺术 04）
细装饰 + 金色辐线，不适合纯监控，备选。

## 挑三张做完整版

选 A（克制叠加）、B（双卡对开）、D（OverSight式单卡强调）——**三个不同骨架、不同气质、不撞账本**：
- dir-1（A）：单卡，左上灯+右侧状态，极简
- dir-2（B）：左右双卡对开，信息密度更高
- dir-3（D）：居中金色/琥珀强调的「设备被访问」通知卡
