# v5xs 自动更新使用说明

v5xs 可以自己下载新版、校验、替换并重启，不必再手动去 Releases 页面下载 DMG。

---

## 快速上手

打开 v5xs → 菜单栏图标 →「设置…」→ 左侧选「更新」。

看到「发现新版本 vX.Y.Z」后，点 **「下载更新」**：

```
下载 → 校验 → 准备安装
```

如果「下载完成后自动重启安装」关闭，准备完成后可在版本旁点 **「更新并重启」**；
开启后，v5xs 会直接退出、安装并重新启动。重启后就是新版本。
「更新内容」旁的「打开」可查看本次更新说明，支持 Markdown 标题、列表、引用、
链接和代码块；检查成功后说明会保留到更新后的首次启动。

> 如果你点了没反应、或者想完全手动，随时可以点旁边的 **「手动下载」**，
> 它会像以前一样在浏览器里打开下载页。

---

## 三个开关

「更新」页里有三个开关，从上到下是递进关系：

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| 自动检查更新（每 24 小时） | **开** | 启动时距上次检查超过 24 小时，就在后台查一次 |
| 发现新版本后自动下载 | **关** | 查到新版后自动下载并校验，但仍然问你 |
| 下载完成后自动重启安装 | **关** | 下载校验完直接退出并重启安装 |

后一档依赖前一档：关掉「自动检查」，下面的「自动下载」会变灰不可用。

### 该开哪些？

**只想不出意外**（推荐）：保持默认。v5xs 会提醒你有新版，你想装的时候点一下。

**想省事但保留控制权**：打开「自动下载」。v5xs 会在后台把包下好、校验好，
等你在版本旁点「更新并重启」时几秒钟就能装完。

**完全不管**（适合自己用、不在意偶尔被打断）：三个全开。
v5xs 发现新版会自动装好并重启。**注意**：这会让应用在你工作时自行退出重启。

---

## v5xs 会替你检查什么

自动安装是个「把执行权限交给远程服务器」的动作，所以每一层校验都是硬性的，
任何一项不过就不安装：

| 检查 | 不过会怎样 |
| --- | --- |
| 清单的 Ed25519 签名 | 拒绝安装，提示「可能被篡改」 |
| 安装包大小 | 拒绝，删除下载的文件 |
| 安装包 SHA-256 | 拒绝，删除下载的文件 |
| 包内的 BundleID | 拒绝，防止被换成别的应用 |
| 磁盘剩余空间 | 提前拒绝，提示还差多少 |
| 是否从只读位置运行 | 提前拒绝，提示手动安装 |
| 是否有多个 v5xs 在跑 | 提前拒绝，提示先退出其他实例 |

安装包在替换前会**先备份**，替换失败会自动回滚到旧版本；
如果替换后新版本打不开，下次启动时也能从备份恢复。

## 常见情况

### 「无法自动安装：v5xs 所在位置不可写」

说明 v5xs 不在可写的位置，最常见的是**直接在 DMG 里双击运行**，没拖进「应用程序」。

解决办法：把 v5xs 拖进「应用程序」文件夹，重新打开，再点一次更新。

如果已经装在「应用程序」里还报这个错，可能是权限问题，用「手动下载」装一次即可。

### 「检测到多个 v5xs 正在运行」

v5xs 同时跑了两个实例（比如一个在「应用程序」，一个从项目目录里直接启动）。
同时更新会互相踩踏，所以被拦下了。

到活动监视器里退出多余的实例，只留一个再更新。

### 「磁盘空间不足」

提示里会写清需要多少、你还剩多少。清理一些空间后重试即可。

一般需要安装包大小约 3 倍的余量（下载的 DMG + 解压出的新版本 + 旧版备份同时存在）。

### 「安装包校验失败」

下载过程中文件损坏了。v5xs 会删掉损坏的文件，直接再点一次「下载并安装」即可。

如果反复失败，可能是网络中间设备在改内容，建议用「手动下载」。

### 点了更新，应用退出了但没起来

v5xs 会等旧进程最多 15 秒再开始替换。如果替换失败，会自动恢复旧版本并重新打开。
极少数情况下（比如替换时断电）可能留下一个 `v5xs.app.v5xs-old` 目录，
这时从「应用程序」里删掉 v5xs，重新用「手动下载」安装一次即可。

### 更新后想回到旧版本

自动更新不提供降级。需要旧版就去 [Releases](../../releases) 页面下载对应版本的 DMG 手动安装。

> 注意：v5xs 只认「构建号更大」为更新，所以装回旧版后，即使有新版也不会自动提示
> 直到有新版本发布。

## 关于安全

v5xs 目前用 **ad-hoc 签名**（没有 Apple 开发者证书和公证）。这意味着：

- 首次手动下载安装时，macOS 的 Gatekeeper 可能拦截，需要在
  「系统设置 → 隐私与安全性」里点「仍要打开」。
- **自动更新反而不受影响**：v5xs 自己下载的文件不带隔离标记，不会被 Gatekeeper 拦截。

自动更新的安全保障来自：

1. 全程 HTTPS
2. 更新清单带 **Ed25519 签名**，公钥硬编码在 v5xs 里
3. 安装包的 SHA-256 必须与清单完全一致

换句话说，安全边界是「你信任 v5xs 发布者保管好的那一个私钥」，
而不是「你信任 Apple 的公证体系」。

技术细节见 [update-signing.md](update-signing.md)。

---

## 出问题时

自动更新失败不会静默：失败原因会显示在「设置 → 更新」页里。
如果那里也没说清，可以：

- 用「手动下载」走传统方式
- 到 [Releases](../../releases) 页面看最新版本号

想反馈问题时，附上「设置 → 更新」页的提示文字会很有帮助。
