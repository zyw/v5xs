## 菜单栏养了只小动物，系统越忙跑得越快

第一眼看到它，我就被可爱到了。

它不是那种密密麻麻的仪表盘，而是让你在菜单栏「养一只小动物」：

- 系统空闲，它慢悠悠地散步；
- CPU 一飙，它立刻撒腿狂奔；
- 负载越重跑得越快，低速时依然连贯不卡顿。

关键它还能换形象——猫、兔、狐、狗、马、恐龙、青蛙、鸡、鸭、鱼，十几种随你挑。

你可能觉得这只是卖萌，但用过你会发现——

> **它其实是把「抽象的系统负载」，翻译成了你一眼就能看懂的直觉。**

不用盯数字，瞄一眼菜单栏，就知道电脑现在忙不忙。**这就是简洁的魔力。**

## 点开就是一张「实时体检表」，什么都能看

左键点开，面板依旧走「极简风」，但该有的全都有，全部数据实时真实：

- **CPU**：占用多少、8 核（4 性能 + 4 能效）拓扑排得明明白白
- **GPU 活跃度**：你在剪视频、跑设计稿时它真的会动
- **内存**：12.3G/16G，用没用满一眼分清
- **磁盘**：可用空间 + 实时读写速度
- **网络**：上传 / 下载曲线，今天谁在偷流量一清二楚
- **温度**：CPU / GPU 实时温度，过热前先预警

它甚至还带**外设电量环**——蓝牙鼠标还能撑几天，键盘有没有电，光圈里一步到位。

最实用的，是那个**高占用进程榜**：谁在吃内存、谁在烧 CPU，排好队摆你面前，一点就能终止或强制退出。

**功能又多又全，却一点也不乱——这就是「简洁到离谱」的正确打开方式。**

## 最让我惊喜的：它居然还是个「卸载神器」

冲着监控来的，结果被它的卸载功能圈粉了。

点一下面板顶部的评分卡片，打开一个独立的**软件卸载窗口**：

- 按 **名称 / 占用体积 / 最近使用 / 安装时间** 任意排序
- 可以**批量勾选**想卸的 App
- 展开每个 App，帮你揪出藏在各处的**关联文件**——缓存、容器、WebKit、偏好设置、甚至 `/var/folders` 里的临时文件

App 本体 + 残留文件一起挪进废纸篓，**一次卸得干干净净**。

再也不用担心「删了个图标，还留一堆垃圾占着硬盘」。

## 顺手还能管开机自启项

除了监控和卸载，v5xs 还自带一个**启动项管理**。

登录项、LaunchAgent、LaunchDaemon，全部按来源分组列得清清楚楚。

**哪些程序一开机就悄悄加载，由你说了算**——不想要的，一键关掉，让开机能快上几秒。

## 数据真实，不玩虚的

这一点我特别看重。

v5xs 所有数据都来自系统实时状态，**不编造、不糊弄**。温度读取针对 Mac14,2 验证过，其他机型读取失败时，它诚实显示「—」，而不是给你个假数字骗你安心。

面向 **macOS 14+**，我自己在 **macOS 26.4（M2）** 上测得很顺。
