# v5xs 0.1.2

> 发布日期：2026-10-26 · 构建号 4 · 最低系统 macOS 14.0

本次更新的重点是**修好「高占用进程」列表里点了没反应的问题**；同时新增了**可配置的监测刷新频率**，并调整了设置窗口与电量环的布局。

## 新增

### 监测刷新频率可在设置中调整

设置页新增「监测」分区，可以在四档之间选择采样频率：

| 档位 | 间隔 | 适用场景 |
| --- | --- | --- |
| 极快 | 0.5 秒 | 观察瞬时峰值与编译、录音等短时负载 |
| 标准 | 1 秒 | 默认，兼顾精度与开销 |
| 平稳 | 2 秒 | 日常查看，开销更低 |
| 省电 | 5 秒 | 只看趋势，最省电 |

改动**立即生效**，无需重启。面板底部的状态文案（如 `v0.1.2 · 每 2 秒更新`）会跟随所选档位同步变化。

频率越高曲线越细腻，但采样本身也会占用少量 CPU，可按机器状况自行取舍。旧版本的「低延迟模式」开关会自动迁移为对应档位，原有偏好不会丢失。

## 修复

### 健康评分一直停在「采集中」

面板顶部的健康评分可能长期显示「采集中」而不出分数。原因是采样定时器的创建逻辑中有一处提前返回，导致定时器从未真正建立，采样循环完全没有运行，评分所需的 CPU 与内存数据因此始终为空。现已修正，并补充了回归测试防止再次出现。

### 终止 / 强制退出对多数进程无效

进程列表里的「终止」和「强制退出」在多数条目上点了没有效果，或只弹出一个「进程已经结束」的误报对话框。实测进程榜前 5 行中有 4 行无法操作。

原因是终止前的双重身份校验存在两个独立缺陷：

- **非 GUI 进程无法通过校验**：原先用 `NSRunningApplication(processIdentifier:)` 判断进程是否可用，但该 API 只识别带 `.app` 包的 GUI 应用，对 java、各类 Helper、守护进程一律返回 `nil`（实测全系统 637 个进程中 83% 返回 `nil`）。而这些正是进程榜的主要成员，校验直接提前返回，信号从未发出。
- **路径被内核截断**：校验用 `ps -o comm=` 的输出比对完整路径，但 `comm` 取自内核 `p_comm`，只有 16 字节上限。长路径必然被截断（如 `Google Chrome He`），与完整路径永不相等。

现在改用 `libproc` / `sysctl` 读取进程的**完整路径**与**启动时间（epoch 秒）**，不再依赖 `ps` 文本与 `NSRunningApplication`。启动时间做防 PID 复用的二次确认，确认期间进程被替换会拒绝操作，避免误杀。

两种操作的行为也做了区分：

- **终止** 发送 `SIGTERM`，给进程自行清理退出的机会；
- **强制退出** 发送 `SIGKILL`，进程无法拦截。确认框会在真正发送信号前再次校验身份。

权限不足时（进程属于其他用户或受系统保护）会给出明确提示，而不是笼统失败。

### 「在访达中显示」对非 GUI 进程失效

同样是 `NSRunningApplication` 的问题。现在会退化为沿可执行路径向上查找所在的 `.app` 目录。

## 界面调整

### 进程列表支持鼠标悬停高亮

鼠标经过进程行时整行提亮，进程名转为薄荷绿，右侧操作图标点亮。悬停区域覆盖整行而非仅文字，鼠标移到行中间空白处不会中断高亮。

### 进程列表字色压暗

正文文字比原先更沉，避免列表在深色卡片上过于抢眼。CPU 超过 50% 时的琥珀色预警保留，作为异常信号。已确认文字与卡片底色的对比度为 4.66:1，符合 WCAG AA 小字下限，压暗后仍然清晰可读。

### 设置窗口不再出现滚动条

设置页内容实际需要 583pt 高度，而窗口此前固定为 500pt，因此打开即出现滚动条。现在窗口高度按内容自适应，默认打开正好贴合内容；最小高度也对齐内容，并受屏幕可用高度约束，不会在小屏上伸出屏幕外。

### 电量环尺寸与布局

鼠标 / 键盘电量环此前 49pt，会顶到上方的横向分隔线。现调整为：

| 项目 | 调整前 | 调整后 |
| --- | --- | --- |
| 环直径 | 49pt | 34pt |
| 环宽 | 5pt | 4pt |
| 图标字号 | 17pt | 12pt |
| 两环间距 | 10pt | 14pt |

两个环现在与左侧 MacBook 区块垂直居中对齐，间距也更宽松。

## 更新清单

自动更新的清单由 CI 在发版时**从 Release 里的真实 DMG 现算**，不再依赖仓库中已提交的 `dist/update.json`（该目录被 `.gitignore` 忽略，此前导致发布工作流必然失败）。清单中的文件大小与 SHA-256 因此始终与实际安装包逐字节一致。

## 安装

从 [Releases](../../releases) 下载 `v5xs-0.1.2-macOS-26.4-arm64.dmg`，打开后把 v5xs 拖入「应用程序」文件夹。

已安装旧版本的用户可在设置页点「检查更新」直接获取下载地址。

## 已知限制

- 安装包为 ad-hoc 签名，首次打开可能被 Gatekeeper 拦截，需在「系统设置 → 隐私与安全性」中允许。
- 进程榜展示的是单个进程而非整个应用。结束 IDEA 的辅助进程（如 `fsnotifier`）不会关闭主界面，属预期行为。
- CPU / GPU 温度仅在已验证机型（Mac14,2）上读取。
