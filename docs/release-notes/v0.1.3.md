# v5xs 0.1.3

> 发布日期：2026-10-27 · 构建号 5 · 最低系统 macOS 14.0

本次更新的重点是 **v5xs 现在可以自己下载、校验并安装新版**，不再需要手动去 Releases 页面下载 DMG。另外新增了 5 个菜单栏动物形象，暂停动画时也会显示专属图标。

## 新增

### 自动更新：下载、校验、替换、重启，全自动

设置页「更新」分区里，点「下载并安装」后 v5xs 会自己完成整个流程：

```
下载 → 校验 → 挂载 → 替换 → 自动重启
```

全程通常十几秒。原来的「手动下载」入口仍然保留，作为自动安装失败时的退路。

### 三个可配置的开关

「更新」页新增三档递进开关，默认配置兼顾省心与安全：

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| 自动检查更新（每 24 小时） | 开启 | 后台静默检查是否有新版 |
| 发现新版本后自动下载 | 关闭 | 自动下载并校验，但仍询问你是否安装 |
| 下载完成后自动重启安装 | 关闭 | 下载校验完直接退出并重启安装 |

后一档依赖前一档：关掉自动检查，自动下载会自动变灰不可用。

**默认关闭自动安装**是有意为之——它会让应用在你工作时自行退出重启，应该由你显式开启。

### 签名的更新清单

自动安装意味着「把执行权限交给远程服务器」，所以更新清单现在带 **Ed25519 签名**，公钥硬编码在应用内。

这一步是必要的：清单里的 SHA-256 和清单本身来自同一个 HTTPS 响应，一旦清单源被劫持，两者可以一起被替换，SHA-256 校验毫无意义。有了签名，攻击者必须同时拿到私钥才能伪造更新。

v5xs 在安装前会依次检查：

- 清单签名（拒绝未签名或签名不符的清单）
- 安装包大小与 SHA-256（不通过就删除文件，绝不安装）
- 包内 BundleID（防止被替换成别的应用）
- 磁盘剩余空间、是否从只读位置运行、是否有多个实例在跑

### 5 个新的菜单栏动物

新增「短跑手」「闪电」「龙」「熊猫」「老虎」五个奔跑动画，均支持简繁英三种名称。

### 暂停动画时显示专属图标

以前暂停动画会把动物冻在当前帧，看起来像卡住了。现在暂停后会显示 v5xs 的 Logo 剪影，明确表达「已暂停」。恢复动画时自动切回你选的动物。

## 修复

### 菜单「检查更新」跳转到了错误页面

右键菜单点「检查更新」会打开设置窗口，但停在「通用」页，用户以为没反应。现在会正确跳到「更新」分区。

同时修正了相反方向的问题：从「检查更新」跳到更新页后，再点「设置」仍停留在更新页。现在每个入口都对应确定的分区——「设置」总是回到「通用」。

### 菜单栏图标在部分时机显示错误

启动应用或切换动物时，即使处于暂停状态也会显示动物动画，静默「解开」了暂停。现已统一走同一套图标更新逻辑。

## 界面调整

### 设置页改为左侧导航

设置项变多后单页过长了，改为左侧分区导航 + 右侧内容：

`通用` · `监测` · `更新` · `语言` · `关于`

### 设置窗口高度智能适配

窗口高度按内容自适应，不会被固定尺寸挤出滚动条；同时受屏幕可用高度约束，小屏笔记本上不会伸出屏幕外。

## 发版与安全

### 更新清单改由 CI 生成

清单不再依赖仓库中提交的 `dist/update.json`（该目录被 `.gitignore` 忽略，此前导致发布工作流必然失败），改为 CI 在发版时从 Release 里的真实 DMG 现算，文件大小与 SHA-256 因此始终与实际安装包逐字节一致。

### 发布流程新增签名步骤

发布工作流会从仓库 secret 读取私钥、签名清单，并用**仓库里的公钥复验**一次，确认公私钥配对——两者不配对时所有已安装客户端都会拒绝更新，必须在发布前拦住。私钥在流程结束后立即清理。

> **注意**：未配置 secret `V5XS_UPDATE_SIGNING_KEY` 时，发布工作流会故意失败。这是有意的设计：产出一个没有签名的清单，会让用户更新时静默失败，比发版时报错难排查得多。配置方法见 [docs/update-signing.md](../update-signing.md)。

## 安装

从 [Releases](../../releases) 下载 `v5xs-0.1.3-macOS-26.4-arm64.dmg`，打开后把 v5xs 拖入「应用程序」文件夹。

已安装 0.1.2 的用户：这是最后一个需要手动下载的版本。从 0.1.3 开始，后续版本可以自动更新。

用户侧使用说明见 [docs/auto-update-guide.md](../auto-update-guide.md)。

## 已知限制

- 安装包为 ad-hoc 签名，首次手动下载安装可能被 Gatekeeper 拦截，需在「系统设置 → 隐私与安全性」中允许。**自动更新不受此影响**（v5xs 自己下载的文件不带隔离标记）。
- 自动更新的安全边界是「信任发布者保管的私钥」，而非「信任 Apple 的公证体系」。将来若采用 Developer ID 签名与公证，可以叠加完整的代码签名校验。
- 自动更新不提供降级；需要旧版请到 Releases 页面手动下载安装。
- 进程榜展示的是单个进程而非整个应用。结束 IDEA 的辅助进程（如 `fsnotifier`）不会关闭主界面，属预期行为。
- CPU / GPU 温度仅在已验证机型（Mac14,2）上读取。
