# v5xs 0.1.4

> Released 2026-10-30 · Build 6 · Requires macOS 14.0 or later

Version 0.1.4 improves the software uninstaller and adds localized UI and project links.

## What's New

- **Localized uninstaller**: The uninstall window is available in Simplified Chinese, Traditional Chinese, and English.
- **Easier app management**: Open the uninstaller from System Overview, search for apps, sort by name, disk usage, last used, or install date, and select multiple apps at once.
- **Review related files before uninstalling**: Inspect and select app-related files individually, then move the selected items to the system Trash after confirmation.
- **Project links in About**: Open the project page, homepage, and author's GitHub profile directly.
- **Refreshed app icon and animal artwork**: Updated the project icon assets and added the panda menu bar character.
- **Organized README image references**: Documentation images are now grouped under `docs/`.

## Install

Download the DMG that matches your device. The filename includes the app version, macOS version, and CPU architecture, for example:

`v5xs-0.1.4-macOS-26.4-arm64.dmg`

Open the DMG and drag v5xs to the Applications folder.

## Known Limitations

- The app is ad-hoc signed. Gatekeeper may block the first manual launch; if prompted, allow it under System Settings → Privacy & Security.
- CPU / GPU temperatures are only available on the validated model (Mac14,2). Other models show “—” when the reading source cannot be confirmed.
