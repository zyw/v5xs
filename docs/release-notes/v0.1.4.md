# v5xs 0.1.4

> 发布日期：2026-10-30 · 构建号 6 · 最低系统 macOS 14.0

v0.1.4 改进了软件卸载体验，并补齐多语言界面与项目入口。

## 更新内容

- **软件卸载支持多语言**：卸载窗口可使用简体中文、繁体中文或英文显示。
- **更方便地管理应用**：在系统概览中打开卸载窗口，可搜索应用、按名称／占用体积／最近使用／安装时间排序，并批量选择应用。
- **卸载前检查关联文件**：逐项查看并选择应用文件，确认后移到系统废纸篓。
- **关于页面新增项目链接**：可直接打开项目主页、个人主页和作者 GitHub。
- **更新应用图标与动物形象**：替换项目图标资源，并加入熊猫菜单栏形象。
- **更新 README 图片资源引用**：文档图片统一整理到 `docs/`。

## 安装

下载与当前设备匹配的 DMG，文件名包含应用版本、macOS 版本和 CPU 架构，例如：

`v5xs-0.1.4-macOS-26.4-arm64.dmg`

打开 DMG 后，将 v5xs 拖入“应用程序”文件夹。

## 已知限制

- 安装包为 ad-hoc 签名，首次手动下载安装可能被 Gatekeeper 拦截；如遇到提示，请在“系统设置 → 隐私与安全性”中允许打开。
- CPU / GPU 温度仅在已验证机型（Mac14,2）上读取；其他机型无法确认数据来源时显示“—”。
