# v5xs 0.1.5

> Released 2026-11-01 · Build 7 · Requires macOS 14.0 or later

Version 0.1.5 reworks the update panel: release notes can be read inside the app, downloading and installing are now two separate steps, and background updates no longer interrupt you.

## What's New

### Read release notes inside the app

The Updates section in Settings has a new **"What's New"** row. After a successful update check, click **"Open"** to read this release's notes in a sheet.

Notes render as Markdown: headings, lists, quotes, code blocks, and links all display correctly, and links are clickable.

**Notes are kept until the first launch after the update** — after restarting into the new version you can still read what that release changed, instead of seeing an empty "No release notes available".

### Download and install are now two steps

Previously a single "Download and Install" click made the app quit and restart immediately, with no way to back out. The button is now **"Download Update"** and only downloads, verifies, and prepares the install:

```
Download → Verify → Prepare install
```

Once preparation finishes, an **"Update and Restart"** button appears next to the version, so you choose when to restart. Work in progress is no longer interrupted mid-download.

If you prefer it hands-off, turn on "Automatically restart and install after download" and v5xs will quit, install, and relaunch as soon as preparation completes — the same behaviour as before.

> **Toggle semantics fixed**: automatic restart now requires **both** "Automatically download new versions" and "Automatically restart and install after download". Previously only the latter was checked, so turning off auto-download could still trigger an unexpected restart.

### Background updates no longer interrupt with a dialog

When a background update finished preparing, a modal alert used to appear and had to be dismissed. That was an interruption in disguise. It is now a silent restart: if you explicitly enabled automatic restart in Settings, no extra confirmation is needed.

Failure handling is fixed as well: a failed background update no longer clears its state. The error used to be reset immediately, so opening Settings showed nothing — the reason is now preserved for you to inspect.

### Version info consolidated at the top

Version, status, and action buttons now share one row, so state changes (downloading, verifying, preparing, ready) appear next to the actions you can take instead of forcing you to look in two places.

### Missing English error strings added

The English UI was missing four update error strings (not enough disk space, multiple instances running, install preparation failed, install hint) and fell back to Chinese. They are now translated, so all three languages are complete.

### Website and docs

- Added a bilingual website (`website/`) with screenshots and a download entry point.
- README image references consolidated under `images/`.

## Install

Download the DMG that matches your device. The filename includes the app version, macOS version, and CPU architecture, for example:

`v5xs-0.1.5-macOS-26.4-arm64.dmg`

Open the DMG and drag v5xs to the Applications folder.

Already on 0.1.4? Open Settings → Updates and click "Check for Updates", or wait for the background check, to see and install this version.

## Known Limitations

- The app is ad-hoc signed. Gatekeeper may block the first manual launch; if prompted, allow it under System Settings → Privacy & Security.
- CPU / GPU temperatures are only available on the validated model (Mac14,2). Other models show "—" when the reading source cannot be confirmed.
- Automatic updates do not support downgrades; grab an older version from the Releases page if you need it.
