# v5xs 0.1.5

> 发布日期：2026-11-01 · 构建号 7 · 最低系统 macOS 14.0

v0.1.5 重构了更新面板的交互：更新说明可以直接在应用内查看，下载与安装拆成了两步，后台自动更新也不再打断你。

## 更新内容

### 应用内查看更新说明

设置页「更新」分区新增 **「更新内容」** 一行。检查更新成功后，点右侧 **「打开」** 即可在弹出的窗口中阅读本版发行说明。

说明支持 Markdown 渲染：标题、列表、引用、代码块与链接都能正常显示，链接可点击打开。

**更新说明会保留到更新后的首次启动**——重启装好新版后，你依然能看到刚刚那一版的更新内容，而不是空白的「暂无更新说明」。

### 下载与安装拆成两步

原来点一次「下载并安装」，应用会立刻退出重启，没有回旋余地。现在按钮改为 **「下载更新」**，只负责下载、校验并准备安装：

```
下载 → 校验 → 准备安装
```

准备完成后，版本号旁边会出现 **「更新并重启」** 按钮，由你决定什么时候重启。这样不会在下载到一半时被强行中断工作。

想省事的话，在设置里打开「下载完成后自动重启安装」，v5xs 会在准备完成后直接退出、安装并重新启动，与之前的行为一致。

> **开关语义修正**：自动重启现在要求「发现新版本后自动下载」与「下载完成后自动重启安装」**同时开启**。此前只判断后者，容易出现「关了自动下载却仍被自动重启」的意外。

### 后台自动更新不再弹窗打断

后台自动更新准备完成时，原来会弹出一个模态提示框，必须点掉才能继续，实际上是一种打断。现在已改为静默重启：既然你已经在设置里明确开启了自动重启，就不需要再确认一次。

同时修正了失败处理：后台更新失败不再把状态清空。之前失败信息会被立即重置，用户打开设置页什么也看不到；现在会保留原因，你随时能查。

### 版本信息集中在顶部

版本号、状态与操作按钮合并到同一行，状态变化（下载中、校验中、准备安装、已就绪）与可执行动作出现在同一处，不用再上下对照。

### 补齐英文错误提示

英文界面此前缺少 4 条更新错误文案（磁盘空间不足、多实例运行、安装准备失败、安装提示），会回退显示中文。现已补全，三语界面文案完整。

### 官网与文档

- 新增中英文官网页面（`website/`），含界面截图与下载入口。
- README 图片引用统一整理到 `images/` 目录。

## 安装

下载与当前设备匹配的 DMG，文件名包含应用版本、macOS 版本和 CPU 架构，例如：

`v5xs-0.1.5-macOS-26.4-arm64.dmg`

打开 DMG 后，将 v5xs 拖入“应用程序”文件夹。

已安装 0.1.4 的用户：打开「设置 → 更新」点「检查更新」，或直接等待后台检查，即可看到并安装本版。

## 已知限制

- 安装包为 ad-hoc 签名，首次手动下载安装可能被 Gatekeeper 拦截；如遇到提示，请在“系统设置 → 隐私与安全性”中允许打开。
- CPU / GPU 温度仅在已验证机型（Mac14,2）上读取；其他机型无法确认数据来源时显示“—”。
- 自动更新不提供降级；需要旧版请到 Releases 页面手动下载。
