常见问题

开始之前，
再说几句。

安装、兼容性和权限，都在这里。

v5xs 需要什么系统？

支持 macOS 14 或更高版本，提供 Apple Silicon 与 Intel 架构的安装包。请在 GitHub Releases 页面选择适合设备的 DMG。

第一次打开时被 macOS 拦住怎么办？

当前安装包采用 ad-hoc 签名。首次安装如遇 Gatekeeper 提示，可到“系统设置 → 隐私与安全性”允许打开。

会自动重启更新吗？

由你决定。自动检查、自动下载与自动重启安装分别有开关；关闭自动重启后，可在更新准备完成时手动点“更新并重启”。

所有温度读数都可用吗？

温度读取目前针对已验证的 Mac14,2 机型；其他机型若无法确认数据来源，会显示不可用，其他监控功能不受影响。
